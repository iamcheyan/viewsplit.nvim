*viewsplit.nvim* Manage independent view-local state for splits of one buffer.

SETUP                                                   *viewsplit-setup*

    require("viewsplit").setup({
        search = true,
        folds = false,
        jumps = false,
        scroll = false,
        selection = false,
    })

Calling setup() without options enables the per-window search layer. Fold,
jump-history, scroll-context, and Visual snapshot layers are opt-in. Mark APIs
are available independently and do not replace Neovim's native marks.

API                                                       *viewsplit-api*

`require("viewsplit").current_view()` returns the current window's state table.
`require("viewsplit").view(winid)` returns state for a window ID.
`require("viewsplit").current_view_id()` returns the focused window ID.
`require("viewsplit").selection_state(winid)` returns saved selection state.

`set_mark(name, {row, col}, winid)`, `get_mark(name, winid)`, and
`del_mark(name, winid)` manage independent lowercase named view marks.
`jump_back(winid)` and `jump_forward(winid)` traverse the opt-in cursor history.
These APIs do not replace `<C-o>` or `<C-i>`.

`:ViewInfo` displays the current view state. `:ViewSync` reapplies stored local
search matches.

SEARCH                                                   *viewsplit-search*

Each window stores its own `/` or `?` pattern and uses a window-local match. On
window entry the pattern is restored to the `/` register, so native `n` and `N`
continue that view's search. Global `hlsearch` is disabled by this layer.

FOLDS                                                   *viewsplit-folds*

When `folds = true`, window-local fold options and closed fold ranges are
captured on window leave and restored on window entry. Fold methods that
produce the same ranges in the shared buffer are required in each view.

JUMP HISTORY                                           *viewsplit-jump-history*

When `jumps = true`, cursor positions are recorded per view and can be
traversed through `jump_back()` and `jump_forward()`. Native `<C-o>` and
`<C-i>` mappings are left unchanged.

MARKS                                                     *viewsplit-marks*

The mark API stores lowercase one-character names in each view's in-memory
state. These marks are separate from Neovim's buffer-local and global marks.

SCROLL                                                   *viewsplit-scroll*

When `scroll = true`, cursor position and `winsaveview()` viewport fields are
saved and restored per window, including topline, left column, skip column, and
desired cursor column.

SELECTION                                           *viewsplit-selection*

When `selection = true`, Visual ranges are stored by window. Inactive sibling
views render saved ranges through Neovim 0.12's per-window ephemeral decoration
provider. Neovim still has one native active Visual selection; inactive ranges
are overlays. Characterwise, linewise, blockwise, multibyte, and
`selection=exclusive` capture pass the region tests. Characterwise inactive
overlay pixels pass the configured-theme TUI probe. Range tracking through
edits and third-party highlight namespace compatibility remain unverified.

LIMITATIONS                                           *viewsplit-limitations*

State is in memory and keyed by window ID; it is removed when the window
closes. The plugin retains Neovim's shared-buffer model: text and undo history
remain shared. Compatibility with third-party plugins and WSL-specific behavior
must be verified in the target environment before being claimed.
